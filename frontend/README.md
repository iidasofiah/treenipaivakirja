# Treenipäiväkirja

Selainohjelmoinnin harjoitustyö, joka on toteutettu Reactilla, Expressillä ja CSS:llä.

Sovelluksessa voi lisätä, tarkastella, hakea ja poistaa treenejä.

## Käynnistäminen

**Backend:**
```bash
cd backend
npm install
npm run dev
```

**Frontend (toisessa terminaalissa):**
```bash
cd frontend
npm install
npm run dev
```

Sovellus avautuu osoitteessa http://localhost:5173.

Treenit tallennetaan backendin muistiin, joten ne palautuvat alkutilaan palvelimen käynnistyessä uudelleen.
